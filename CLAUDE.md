# null-safety

Java 26 project demonstrating null safety techniques.

## Build

```
mvn compile
mvn exec:java -Dexec.mainClass="com.gupta.nullsafety.JSpecifyDemo"
```

## Run the live-coding session file

```
mvn exec:java -Dexec.mainClass="com.gupta.nullsafety.LiveCodingSession"
```

## Source layout

- `src/main/java/com/gupta/nullsafety/` — all Java source files
- `assets/docs/` — AsciiDoc slides
