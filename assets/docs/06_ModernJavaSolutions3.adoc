== Null-hostile collections

The immutable collections returned by Java 9+ factory methods are null-hostile and will throw a NullPointerException if you attempt to store a null value.

* `List.of(...)`
* `Set.of(...)`
* `Map.of(...)`


[source, java, line, linenums, highlight="3"]
----
List<Coffee> menu = List.of(
 new Coffee("Espresso", "Ethiopian", "Grind fine."),
 null // NPE fires here, not when iterating later            <1>
);
----
<1> Using null-hostile collections throws NullPointerException upon initialization.
